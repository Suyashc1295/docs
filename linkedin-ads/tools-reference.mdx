Use HireOtto's LinkedIn Ads tools to move from account discovery to reporting, targeting research, image management, and reviewable campaign changes from an MCP-capable AI client.

Start by confirming the ad account, your role, and write capability. Read the current hierarchy before using IDs in later requests. For campaign work, validate first, create in draft, inspect the saved objects, preview the ad in Campaign Manager, and activate only after approval.

<Info>
  LinkedIn Ads is available on the Free trial, Starter, Pro, and Agency plans. Reporting and discovery tools are read-only. Creation, update, image-upload, and authorization tools can save data in HireOtto or LinkedIn. Your LinkedIn role, Page access, account lifecycle, billing state, and HireOtto plan or credits can still limit an otherwise supported action.
</Info>

## Connect the server

Add this hosted endpoint to a remote MCP-capable client:

```text
https://linkedinads.hireotto.com/mcp
```

Complete the HireOtto sign-in, then connect LinkedIn separately. Use the LinkedIn identity that can access the required Campaign Manager ad account. You do not need your own LinkedIn developer application, API key, terminal, or local server.

See the [LinkedIn Ads quickstart](/linkedin-ads/quickstart) for client-specific setup and the [current pricing page](https://hireotto.com/pricing) for plan details.

The default connection is available on every plan. Additional named LinkedIn profiles require Agency or enabled Enterprise access.

## Shared inputs and safety defaults

| Input | Required | Default | Meaning |
| --- | --- | --- | --- |
| `profile_id` | No | `default` | Saved LinkedIn connection; additional named profiles require Agency or enabled Enterprise access |
| `ad_account_id` | Required for account-specific tools | None | Numeric sponsored-account ID; use the value returned by account discovery |
| `validate_only` | No | `false` | Validate the proposed payload without sending the create or update request |
| `include_raw` | No | `false` | Include LinkedIn's raw entity alongside normalized fields for troubleshooting |

IDs can usually be supplied as numeric IDs or full LinkedIn URNs. Prefer IDs returned by HireOtto. For targeting, use the exact URNs returned by targeting discovery; do not invent or loosely translate entity IDs.

`validate_only=true` checks the request shape and supported rules, but it cannot prove that LinkedIn will accept a later write. Permissions, lifecycle rules, account warnings, budgets, dates, Page access, and platform-side validation are still checked when the real request runs.

## Authentication and account access

### `authenticate_linkedin_ads`

Starts LinkedIn OAuth and returns an authorization URL.

| Parameter | Required | Default | Notes |
| --- | --- | --- | --- |
| `profile_id` | No | `default` | Named profiles require Agency or enabled Enterprise access |

This connects LinkedIn to HireOtto. It is separate from connecting the MCP server to the AI client. The tool does not create an ad account or change campaigns.

<Prompt description="Connect my LinkedIn Ads account using the default profile. Return the authorization link and, after I complete LinkedIn approval, verify the connection. Do not create or change any ads." actions={["copy"]}>
</Prompt>

### `verify_linkedin_ads_connection`

Checks the saved member token, Advertising API account access, and token-expiry state without changing LinkedIn Ads.

| Parameter | Required | Default |
| --- | --- | --- |
| `profile_id` | No | `default` |

Use it after OAuth, after reconnecting, or when account reads begin returning authorization errors. A failed member check or an expired refresh token can require a new authorization.

### `list_linkedin_ad_accounts`

Lists accessible ad accounts and returns the connection state, account ID, name, status, currency when available, the authenticated member's role, and whether the connection can write.

| Parameter | Required | Default | Notes |
| --- | --- | --- | --- |
| `profile_id` | No | `default` | Saved LinkedIn connection |
| `refresh` | No | `false` | Set to `true` after account creation or a permission change |

Possible onboarding states include:

| State | Meaning |
| --- | --- |
| `not_connected` | The MCP server is connected, but no LinkedIn identity is linked |
| `connected_no_accounts` | LinkedIn is linked, but the identity has no accessible ad accounts |
| `account_lookup_failed` | Authorization exists, but account access could not be checked |
| `connected_with_accounts` | One or more ad accounts were found |

Viewer access is read-only. Write actions require a sufficient ad-account role, and sponsored-content workflows can also require access to the associated LinkedIn Page.

<Prompt description="List the LinkedIn Ads accounts available to my default profile. Refresh access from LinkedIn and include each account name, account ID, status, currency, my role, and whether the connection can write. Do not change anything." actions={["copy"]}>
</Prompt>

## Read account and campaign structure

HireOtto provides dedicated tools for exploring LinkedIn ad accounts, campaign groups, ad sets, and creatives. Use these tools to discover IDs, inspect existing settings, and understand campaign structure before reporting or making changes.

### Available tools

| Tool | What it does |
| :-- | :-- |
| `list_linkedin_ad_accounts` | List accessible ad accounts, account roles, and connection status. |
| `get_linkedin_ad_account` | Retrieve details for a specific ad account. |
| `list_linkedin_campaign_groups` | List campaign groups, with optional filters for IDs, names, or status. |
| `get_linkedin_campaign_group` | Retrieve a specific campaign group by ID or URN. |
| `list_linkedin_ad_sets` | List ad sets, optionally filtered by parent campaign group, IDs, names, or status. |
| `get_linkedin_ad_set` | Retrieve an ad set's configuration, including targeting. |
| `list_linkedin_creatives` | List creatives, with optional ad-set, creative-ID, and intended-status filters. |
| `get_linkedin_creative` | Retrieve a creative's content references, lifecycle, and serving information. |
| `get_linkedin_ads_hierarchy` | Retrieve an account-level snapshot of campaign groups, ad sets, and creatives. |

### Parameters and filters

Most entity tools require `ad_account_id`. Individual getters additionally require the corresponding `campaign_group_id`, `ad_set_id`, or `creative_id`.

Listing tools support relevant combinations of:

- `campaign_group_ids`, `ad_set_ids`, or `creative_ids` — filter by existing entity IDs.
- `statuses` or `intended_statuses` — filter by lifecycle status.
- `names` — filter by entity name where supported.
- `page_size` and `page_token` — navigate paginated results.
- `include_raw` — include underlying LinkedIn API data where supported.
- `profile_id` — select a connected LinkedIn profile; omit for the default connection.

Not every parameter applies to every tool. For example, `list_linkedin_creatives` uses `intended_statuses`, while campaign-group and ad-set listings use `statuses`.

ID-filtered results may be returned as objects keyed by ID rather than arrays.

### Full hierarchy vs. focused reads

Use `get_linkedin_ads_hierarchy` when you want a broad overview of an account's structure or need to identify related parent and child entities.

The hierarchy snapshot is bounded and may not include every entity in very large accounts. Use the dedicated listing tools with pagination when completeness matters.

For a single campaign group, ad set, or creative, prefer the corresponding getter rather than retrieving the entire hierarchy.

### Important behavior

- These tools read advertising entities without changing their campaign settings or creative content.
- `list_linkedin_ad_accounts` can refresh saved account information and permissions using `refresh=true`.
- LinkedIn ad sets correspond to `adCampaign` entities in LinkedIn's API; campaign groups correspond to `adCampaignGroup` entities.
- `include_raw=true` can expose additional account, member, advertiser, or creative metadata.
- Results depend on the access granted to the connected LinkedIn identity.

### Example prompts

> List my LinkedIn ad accounts and show which ones I have permission to manage.

> Show all active and paused campaign groups in my LinkedIn Ads account, including their IDs, names, budgets, and statuses.

> Retrieve the full campaign hierarchy for account [ACCOUNT_ID]. Show each campaign group's ad sets and creatives.

> Inspect ad set [AD_SET_ID]. Show its current targeting, budget, objective, schedule, and lifecycle status. Do not make changes.

## Discover targeting

HireOtto helps you discover LinkedIn targeting options, resolve valid targeting entities, build audience criteria, and estimate audience size before creating or updating campaigns.

Targeting discovery is read-only. Building criteria or estimating an audience does not apply targeting to an existing ad set.

### Available tools

| Tool | What it does |
| :-- | :-- |
| `list_linkedin_targeting_facets` | List available targeting dimensions and their definitions. |
| `search_linkedin_targeting_entities` | Find targeting entities by text or resolve known LinkedIn URNs. |
| `build_linkedin_targeting_criteria` | Construct a LinkedIn-compatible targeting criteria object from inclusion and exclusion maps. |
| `estimate_linkedin_audience_size` | Validate targeting values and request an estimated audience size. |

### 1. Discover available targeting facets

Use `list_linkedin_targeting_facets` to explore the dimensions supported by LinkedIn.

These can include locations, companies, job titles, seniorities, and other professional targeting attributes.

The tool does not require an ad account ID. An optional `profile_id` selects the connected LinkedIn profile.

### 2. Find targeting entities

Use `search_linkedin_targeting_entities` to resolve audience attributes into LinkedIn targeting identifiers.

**Parameters:**

- `facet` — required targeting dimension.
- `query` — optional search text.
- `entity_urns` — optional list of known LinkedIn URNs to resolve.
- `locale_language` — defaults to `en`.
- `locale_country` — defaults to `US`.
- `profile_id` — optional connected profile.

For example, you can search for a company, location, or job title and use the resulting URNs when constructing targeting criteria.

Locale parameters control how entities are searched and localized. They do not automatically add a language restriction to the target audience.

### 3. Build targeting criteria

Use `build_linkedin_targeting_criteria` to construct the targeting object required by LinkedIn ad sets.

The tool accepts:

- `included_targeting` — a map of facets and included values.
- `excluded_targeting` — a map of facets and excluded values.
- `locale_language` and `locale_country` — optional locale settings.
- `profile_id` — optional connected profile.

Example inclusion map:

```text
{
  "locations": ["urn:li:geo:103644278"],
  "companies": ["urn:li:organization:123456"]
}
```

The example identifiers are illustrative; use URNs returned by LinkedIn discovery rather than inventing IDs.

**Important:** Criteria construction does not validate whether the URNs are valid or eligible. Its response explicitly identifies targeting validation as not performed.

### 4. Validate and estimate audience size

Use `estimate_linkedin_audience_size` before applying targeting.

The tool requires a non-empty `included_targeting` map and optionally accepts `excluded_targeting`, locale settings, and `profile_id`.

HireOtto resolves the supplied targeting values, validates the facets and URNs, and requests an audience estimate from LinkedIn.

Invalid targeting values return validation errors that can help identify the problematic criteria.

Audience estimates are directional and are not guarantees of reach, delivery, or campaign performance.

### Recommended workflow

1. Discover the appropriate targeting facets.
2. Search for and resolve the targeting entities.
3. Build the inclusion and exclusion criteria.
4. Validate the values and estimate audience size.
5. Review the proposed audience before creating or updating an ad set.

### Example prompts

> Show the LinkedIn targeting facets available for B2B campaigns, particularly company, job title, seniority, and location.

> Find the LinkedIn targeting entities for marketing directors in the United States. Return the relevant facets and URNs.

> Build targeting criteria for senior marketing professionals in the United States, excluding employees of [COMPANY]. Show the inclusion and exclusion logic without applying it.

> Validate this proposed audience and estimate its size. Identify invalid targeting values or potential restrictions before I use it in an ad set.

## Run LinkedIn Ads reports

### `get_linkedin_ads_report`

Runs performance or professional-demographic reporting across the account, campaign-group, ad-set, or creative level.

| Parameter | Required | Default | Limit or behavior |
| --- | --- | --- | --- |
| `ad_account_id` | Yes | None | Sponsored-account ID |
| `start_date` | Yes | None | `YYYY-MM-DD` |
| `end_date` | No | None | `YYYY-MM-DD`; specify it for a controlled comparison window |
| `level` | No | `campaign` | `account`, `campaign`, `ad_set`, or `creative` |
| `ids` | No | Whole account | IDs at the selected level |
| `pivots` | No | Level's default pivot | One to three supported LinkedIn pivots |
| `metrics` | No | Common delivery, cost, conversion, and engagement fields | Maximum 20 fields after required report fields are included |
| `time_granularity` | No | `ALL` | `ALL`, `DAILY`, `MONTHLY`, or `YEARLY` |
| `profile_id` | No | `default` | Saved LinkedIn connection |
| `output_mode` | No | `summary_and_csv` | `summary`, `summary_and_csv`, or `csv_only`; an invalid value falls back to the default |
| `limit` | No | `50` | Inline rows, 1-5,000 |
| `export_limit` | No | `5,000` | CSV rows, 1-50,000 |
| `export_ttl_minutes` | No | `30` | Link lifetime, 1-1,440 minutes |

Default metrics include `impressions`, `clicks`, `landingPageClicks`, `costInLocalCurrency`, `externalWebsiteConversions`, `likes`, `shares`, and `totalEngagements`, plus `dateRange` and `pivotValues` for interpretation.

Common pivots include `ACCOUNT`, `CAMPAIGN_GROUP`, `CAMPAIGN`, `CREATIVE`, `OBJECTIVE_TYPE`, `SERVING_LOCATION`, `IMPRESSION_DEVICE_TYPE`, and professional-demographic pivots such as `MEMBER_COMPANY`, `MEMBER_INDUSTRY`, `MEMBER_JOB_TITLE`, `MEMBER_JOB_FUNCTION`, `MEMBER_SENIORITY`, `MEMBER_COUNTRY_V2`, and `MEMBER_REGION_V2`.

LinkedIn Ad Analytics does not provide pagination for this workflow. The export and inline limits cap the rows HireOtto returns; they do not create additional rows when LinkedIn returns less data.

<Prompt description="For LinkedIn Ads account ACCOUNT_ID, compare ad-set performance for the previous 30 complete days with the preceding 30 complete days. Include impressions, clicks, landing-page clicks, spend, website conversions, likes, shares, and total engagements. Keep raw values beside calculated CTR, cost per landing-page click, and CPA. Flag small samples and return both an inline decision summary and CSV. Read only." actions={["copy"]}>
</Prompt>

Professional-demographic reporting is aggregated and privacy-protected. Small groups can be suppressed, and demographic results can lag standard performance reporting. Missing rows do not mean zero exposure. Some metrics are incompatible with `MEMBER_*` pivots; reduce the metric set or run one demographic pivot at a time when LinkedIn rejects a combination.

<Prompt description="For LinkedIn Ads account ACCOUNT_ID and ad set AD_SET_ID, break down eligible performance by member seniority for the previous 90 complete days. Include impressions, clicks, and spend only if compatible. Explain privacy suppression, reporting delay, and insufficient-data cases. Do not infer individual identities and do not change targeting." actions={["copy"]}>
</Prompt>

Derived rates such as CTR, CPC, CPM, conversion rate, and CPA should be calculated from the returned raw metrics. State the denominator and do not rank entities from a limited preview without checking row coverage.

## Manage image assets

### `upload_linkedin_image`

Opens an interactive file picker in an MCP Apps-capable client and uploads a JPG, PNG, or GIF to LinkedIn. It returns a reusable `urn:li:image:...` value.

| Parameter | Required | Default | Notes |
| --- | --- | --- | --- |
| `ad_account_id` | Yes | None | Account that will own the image |
| `owner_urn` | No | Resolved from the ad account | Supply only if automatic advertiser resolution fails |
| `asset_name` | No | None | Optional Media Library name |
| `register_in_media_library` | No | `true` | Keep enabled for later discovery and archive/restore |
| `profile_id` | No | `default` | Saved LinkedIn connection |

The upload app works in ChatGPT and Claude web or Desktop when MCP Apps are supported. It does not currently render in Claude Code CLI or the Claude Code VS Code extension.

<Prompt description="Upload the attached LinkedIn ad image to account ACCOUNT_ID, register it in the Media Library, and name it ASSET_NAME. Use the account's advertiser identity automatically. Return the image URN and processing status. Do not create a creative or campaign." actions={["copy"]}>
</Prompt>

### `upload_linkedin_image_bytes`

Uploads image bytes without opening a UI. Use it only when the client can read, encode, and pass the original file programmatically.

| Parameter | Required | Default | Notes |
| --- | --- | --- | --- |
| `ad_account_id` | Yes | None | Account that will own the image |
| `file_name` | Yes | None | File name with extension |
| `content_type` | Yes | None | `image/jpeg`, `image/png`, or `image/gif` |
| `image_base64` | Yes | None | Standard base64 with no data-URL prefix or line breaks |
| `owner_urn` | No | Resolved from the account | Supply only if automatic resolution fails |
| `asset_name` | No | None | Optional Media Library name |
| `register_in_media_library` | No | `true` | Registers the asset for later discovery and archive/restore |
| `profile_id` | No | `default` | Saved LinkedIn connection |

The decoded file limit is 8 MiB. Base64 adds roughly one-third to the payload, and client or model-context limits can be smaller. Do not ask a user to paste base64 into chat, print it, invent it, or split it across calls. If a timed-out upload might have completed, list recent images before retrying to avoid duplicates.

It creates an image asset, not a creative, ad set, or campaign.

### `list_linkedin_image_assets` and `get_linkedin_image_asset`

Use listing when the user refers to a recent upload or when an upload result is no longer in context.

| Tool | Parameters | Defaults and limits |
| --- | --- | --- |
| `list_linkedin_image_assets` | `ad_account_id`, `count`, `start`, `media_library_status`, `profile_id` | `count=10`, clamped to 1-1,000; `start=0`; status `ACTIVE`; use `ARCHIVED` or `null` to recover other assets |
| `get_linkedin_image_asset` | `ad_account_id`, `image_urn`, `profile_id` | Exact image URN required |

### `update_linkedin_image_asset`

Sets `media_library_status` to `ARCHIVED` or `ACTIVE`. Archiving removes the item from the default active listing but does not permanently delete the binary, delete creatives, or pause ads. Only Media Library-registered images are manageable through this tool.

| Parameter | Required | Default |
| --- | --- | --- |
| `ad_account_id` | Yes | None |
| `image_urn` | Yes | None |
| `media_library_status` | Yes | None |
| `profile_id` | No | `default` |
| `validate_only` | No | `false` |

Local validation does not prove the asset belongs to the account or that its processing state permits the change.

## Create campaign entities

HireOtto supports creating LinkedIn campaign groups, ad sets, and creatives through dedicated tools. You can create individual objects or use the combined campaign creation workflow.

The default creation status is `DRAFT` where supported, allowing you to review the setup before activating delivery.

### Available tools

| Tool | What it does |
| :-- | :-- |
| `create_linkedin_campaign_group` | Create a campaign group in an ad account. |
| `create_linkedin_ad_set` | Create an ad set under an existing campaign group. |
| `create_linkedin_creative` | Create a creative under an existing ad set. |
| `create_linkedin_campaign` | Create a campaign hierarchy using a combined workflow. |

### Create a campaign group

Use `create_linkedin_campaign_group`.

**Required parameters:**

- `ad_account_id` — the target LinkedIn ad account.
- `fields` — a structured object containing at least `name`.

**Supported fields include:**

- `name` — required.
- `status` — defaults to `DRAFT`.
- `start`, `end` — scheduling.
- `objective_type` — campaign objective.
- `total_budget_amount`, `daily_budget_amount`, `currency_code` — budget configuration.
- `budget_optimization_strategy`, `bid_strategy` — supported budget and bidding settings.

Use `validate_only=true` to preview the requested creation without submitting the create operation.

### Create an ad set

Use `create_linkedin_ad_set`.

**Required parameters:**

- `ad_account_id`
- `campaign_group_id` — ID of the existing parent campaign group.
- `fields` — structured ad-set configuration, including `name`.

**Supported configuration includes:**

- Status, campaign type, ad format, and objective.
- Daily or total budget, currency, and bidding settings.
- Start and end dates.
- Audience inclusion and exclusion criteria.
- Locale, audience expansion, and other supported delivery settings.

Ad sets default to `DRAFT`.

The ad format is fixed when the ad set is created. Some campaign formats also have additional budget and schedule requirements.

You can supply friendly `included_targeting` and `excluded_targeting` maps or a complete `targeting_criteria` object.

Use targeting discovery and audience estimation before creation when the audience is new or uncertain.

### Create a creative

Use `create_linkedin_creative`.

**Required parameters:**

- `ad_account_id`
- `ad_set_id` — ID of the existing parent ad set.
- `fields` — structured creative configuration.

The creative must specify a supported content source, such as:

- `image_urn`
- `content_reference`
- `content`
- `inline_content`

For a single-image ad, you can provide an available `image_urn` together with fields such as `commentary`, `headline`, `landing_page`, and `cta_label`.

Additional supported fields include `name`, `intended_status`, `image_alt_text`, and `leadgen_call_to_action`.

Creatives default to `DRAFT` intended status.

**Important:** The single-image creative workflow creates Direct Sponsored Content. Its underlying LinkedIn content may be created as `PUBLIC` and `PUBLISHED` even when the advertising creative has `DRAFT` intended status. This is not the same as publishing an ordinary organic post, and the distinction should be reviewed before creation.

### Validation and safety

All three dedicated creation tools support `validate_only=true`.

Validation prepares the operation and may perform preflight reads or targeting checks. It does not submit the create request and does not guarantee that LinkedIn will accept the eventual mutation.

Creation is additive: it does not automatically remove existing entities.

Explicitly setting an entity to `ACTIVE` can enable advertising or spending, subject to LinkedIn's lifecycle and eligibility rules.

If a creation request returns an uncertain result, inspect the current hierarchy before retrying to avoid duplicates.

### Example prompts

> Create a draft LinkedIn campaign group called "Q1 Lead Generation" in account [ACCOUNT_ID]. Set the objective to lead generation and show the proposed configuration before creating it.

> Create a draft ad set under campaign group [CAMPAIGN_GROUP_ID]. Use the approved audience, schedule, and budget. Validate the setup and show any errors before applying.

> Create a draft single-image creative under ad set [AD_SET_ID] using image [IMAGE_URN], headline [HEADLINE], commentary [COMMENTARY], and landing page [URL]. Show the proposed content before creation.

> Inspect the campaign hierarchy for [CAMPAIGN_GROUP_ID] and identify which ad sets or creatives still need to be created. Reuse existing entities rather than duplicating them.

For the complete campaign workflow, see [Create a LinkedIn Ads campaign with AI](https://docs.hireotto.com/linkedin-ads/create-campaign).

## Update campaign entities

HireOtto provides dedicated tools for changing existing LinkedIn campaign groups, ad sets, and creatives. It also supports batch updates, combined hierarchy updates, additive targeting exclusions, and deletion of eligible draft entities.

These operations can change live advertising behavior. Inspect the existing configuration and validate proposed changes before applying them.

### Available tools

| Tool | What it does |
| :-- | :-- |
| `update_linkedin_campaign_group` | Update a campaign group's name, status, schedule, budget, or supported settings. |
| `update_linkedin_ad_set` | Update an ad set's status, budget, schedule, targeting, or supported delivery settings. |
| `update_linkedin_creative` | Update a creative's intended status, name, or supported content fields. |
| `add_linkedin_targeting_exclusions` | Add exclusions while preserving existing targeting criteria. |
| `batch_update_linkedin_ad_sets` | Update multiple ad sets in the same account. |
| `batch_update_linkedin_creatives` | Update multiple creatives in the same account. |
| `update_linkedin_campaign_hierarchy` | Update campaign group, ad sets, and creatives in a combined workflow. |
| `delete_linkedin_draft_ad_set` | Delete an eligible draft ad set. |
| `delete_linkedin_draft_creative` | Delete an eligible draft creative. |

### Update individual entities

Use the corresponding update tool with `ad_account_id`, the entity ID, and a structured `updates` object.

**Campaign group updates**

Use `update_linkedin_campaign_group` with `campaign_group_id`.

Supported updates include name, status, schedule, budget, objective, and supported native fields.

**Ad set updates**

Use `update_linkedin_ad_set` with `ad_set_id`.

Supported updates include status, name, budgets, schedule, targeting, locale, audience expansion, bidding-related settings, and other explicitly supported fields.

**Creative updates**

Use `update_linkedin_creative` with `creative_id`.

Supported updates include intended status, name, content, and lead-generation call-to-action fields.

Each update tool uses an explicit typed schema. Unsupported fields are rejected rather than forwarded as arbitrary API updates.

The update schemas also expose `set_fields` and `delete_fields` for selected LinkedIn-native fields where supported. These can overwrite or remove stored values, so review the full proposed patch.

### Targeting updates vs. additive exclusions

Replacing targeting and adding exclusions are different operations.

Use `update_linkedin_ad_set` when replacing the ad set's targeting configuration.

For friendly targeting replacement, supply **both** `included_targeting` and `excluded_targeting`. Use an empty map for either side when intentionally leaving that side empty.

A complete `targeting_criteria` object also replaces the existing criteria.

Use `add_linkedin_targeting_exclusions` when you only want to add exclusions while retaining the existing targeting.

Required parameters:

- `ad_account_id`
- `ad_set_id`
- `excluded_targeting` — non-empty map of facets and resolved LinkedIn URNs.

HireOtto reads the existing targeting, merges and deduplicates the new exclusions, then validates the resulting criteria.

This tool cannot remove existing exclusions. Avoid concurrent targeting changes while using this read-modify-write workflow.

### Batch updates

Use `batch_update_linkedin_ad_sets` or `batch_update_linkedin_creatives` to change multiple entities in the same ad account.

Both accept an `updates` object keyed by existing entity IDs or URNs.

Each value follows the corresponding single-entity update schema.

For example, you can prepare a batch to pause several ad sets, or update the intended statuses of multiple creatives.

Batch requests may return item-level failures even when the overall request succeeds. Inspect individual results and read back the affected entities.

### Update a campaign hierarchy

Use `update_linkedin_campaign_hierarchy` when a change spans multiple levels of an existing campaign.

Supported sections:

- `campaign_group_update` — requires `campaign_group_id`.
- `ad_set_updates` — map keyed by existing ad-set IDs.
- `creative_updates` — map keyed by existing creative IDs.

At least one section must be supplied.

The tool processes the campaign group, ad-set updates, and creative updates sequentially.

**Important:** This is not an atomic transaction. If a later operation fails, earlier successful changes are not automatically rolled back.

For larger changes, validate the proposed updates, execute after approval, and verify each affected entity.

### Delete eligible draft entities

Use `delete_linkedin_draft_ad_set` or `delete_linkedin_draft_creative` only when permanent removal is intended.

Required parameters are `ad_account_id` and the corresponding `ad_set_id` or `creative_id`.

LinkedIn determines whether a draft is eligible for deletion.

`validate_only=true` returns a deletion preview without issuing the DELETE request. It does not verify entity existence, permissions, or deletion eligibility.

Deletion may be irreversible. Prefer changing status when the intent is to stop delivery rather than permanently remove an entity.

### Validation and verification

All update and deletion tools support `validate_only=true`.

For updates, validation prepares the proposed patch and may perform necessary reads or targeting checks. It does not submit the mutation and does not guarantee LinkedIn's final acceptance.

A successful validation is not a completed update.

Recommended process:

1. Retrieve the existing entity configuration.
2. Identify the exact changes and affected IDs.
3. Validate the proposed operation.
4. Review the changes and approve execution.
5. Apply the update.
6. Retrieve the affected entities again to verify their saved state.

If an execution returns an error, inspect the live state before retrying. A LinkedIn write may have succeeded even if a subsequent response or billing operation failed.

## Check plan and credits

### `get_billing_status`

Returns the current HireOtto plan, billing or trial period, included and used credits, remaining credits when limited, and feature entitlements. It is read-only and does not consume credits.

The current plan model is:

- Free trial: 200 credits or 14 days, whichever comes first
- Starter: 2,000 credits per month
- Pro: 5,000 credits per month
- Agency: unlimited credits, two included seats, and multiple connected profiles

LinkedIn Ads is included on every tier. When a tool is blocked, check for expired trial or billing periods, inactive billing, exhausted credits, a disabled LinkedIn entitlement, or an Agency-only profile request.

## Common failures and recovery

| Failure | What it usually means | What to do |
| --- | --- | --- |
| No tools appear | The MCP endpoint, client authorization, or cached tool list is incomplete | Confirm the endpoint ends in `/mcp`, finish client OAuth, enable the connection, and refresh or reconnect the client |
| No accounts appear | The LinkedIn identity has no accessible account or access has not refreshed | Verify the login in Campaign Manager and rerun account listing with `refresh=true` |
| Read works but write fails | Viewer or insufficient role, missing Page access, account warning, or lifecycle restriction | Check role, `can_write`, Page access, billing, dates, parent status, and Campaign Manager warnings |
| Empty report | No activity, wrong IDs or dates, incompatible readable scope, privacy suppression, or reporting delay | Confirm the account, entity IDs, complete date window, pivot, and metric compatibility |
| Targeting search is ambiguous | Several LinkedIn entities match the business description | Review names and URNs; never choose an ID from text similarity alone |
| Audience count fails | At least one include or exclude value could not be resolved | Search the failing facet again and rebuild the criteria from returned URNs |
| Image upload fails | Unsupported type, excessive payload, inaccessible file bytes, processing failure, or permission issue | Use JPG, PNG, or GIF; keep decoded bytes under 8 MiB; use the interactive app when possible; list recent assets before retrying |
| Creation partially succeeds | A parent was created before a child failed | Preserve returned IDs, inspect the live hierarchy, and resume only the failed step |
| Update is rejected | The field is immutable, incompatible with the ad format, or blocked by lifecycle rules | Read the object, validate a smaller change, and use a new ad set when the format cannot change |
| CSV link has expired | The requested export lifetime ended | Rerun the same read-only report with a suitable TTL up to 1,440 minutes |

## Current boundaries

- Campaign Manager remains the final place to preview rendering, Page identity, billing, review status, and account warnings.
- HireOtto does not currently create LinkedIn Lead Gen Forms.
- The image-upload workflow does not imply support for video or document-ad uploads.
- Creating a creative does not install or validate the LinkedIn Insight Tag, Google Tag Manager, or the destination page.
- Reporting and demographic data can be delayed, incomplete, or privacy-suppressed.
- `validate_only` reduces avoidable payload errors but does not guarantee a later write.
- Create and update workflows are not substitutes for practitioner approval of objective, budget, targeting, copy, destination, measurement, or activation.

## Recommended operating sequence

1. Connect the server and authorize LinkedIn.
2. List accounts with `refresh=true`; confirm account ID, currency, role, and `can_write`.
3. Read the hierarchy and preserve exact parent and child IDs.
4. Run the smallest report or targeting request that answers the current question.
5. Resolve targeting URNs and estimate audience size before campaign creation or targeting updates.
6. Reuse or upload an image and confirm that LinkedIn reports it as available.
7. Validate the complete proposed configuration.
8. Create new objects as drafts and keep every returned ID.
9. Read the live objects back and preview the creative in Campaign Manager.
10. Verify tracking and activate only after named human approval.

This sequence separates platform access, evidence, construction, and activation. It also gives you a clear recovery point if LinkedIn accepts one step and rejects the next.
